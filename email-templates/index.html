🚀 Quick Start

Em 3 Passos:

1. Configurar SMTP

Adicione ao .env.local:

MAIL_HOST=smtp.gmail.com MAIL_PORT=587 MAIL_USERNAME=seu-email@gmail.com MAIL_PASSWORD=sua-senha-app MAIL_FROM=noreply@armazix.com.br

2. Importar e Usar

No seu código:

import { sendVerificationEmailFn, generateVerificationCode } from '@/lib/emailFns' const code = generateVerificationCode() await sendVerificationEmailFn({ email: 'user@example.com', code: code })

3. Testar Localmente

Use Mailtrap gratuito para testes:

1. Criar conta: https://mailtrap.io 2. Copiar credenciais SMTP 3. Visualizar emails no dashboard 4. Testar em clientes reais
